# Contributing to FetchIt

First of all, thank you for helping the project!

## How to Report a Bug
1. Check if there's already an open issue with the same problem.
2. Create a new issue using the "Bug report" template.
3. Describe the steps that led to the error and attach logs from the "Logs" tab.

## How to Suggest a Feature (Feature Request)
Create an issue using the "Feature request" template. Describe the problem the new feature will solve.

## How to Submit Code (Pull Request)
1. Fork the repository and create a branch from `main` (e.g. `feature/my-new-feature`).
2. We use **Conventional Commits** (e.g. `feat: add dark theme` or `fix: resolve pause bug`).
3. Make sure your code builds without errors (`mvn clean install`).
4. Submit your PR and briefly describe what was done.

Thank you!

# Contributing to FetchIt

Сначала спасибо, что хотите помочь проекту! 

## Как сообщить об ошибке (Bug Report)
1. Проверьте, нет ли уже открытого Issue с такой же проблемой.
2. Создайте новый Issue, выбрав шаблон "Bug report".
3. Опишите шаги, которые привели к ошибке, и приложите логи из вкладки "Логи".

## Как предложить фичу (Feature Request)
Создайте Issue, выбрав шаблон "Feature request". Опишите, какую проблему решит новая функция.

## Как отправить код (Pull Request)
1. Форкните репозиторий и создайте ветку от `main` (например, `feature/my-new-feature`).
2. Мы используем **Conventional Commits** (например, `feat: add dark theme` или `fix: resolve pause bug`).
3. Убедитесь, что ваш код собирается без ошибок (`mvn clean install`).
4. Отправьте PR и кратко опишите, что было сделано.

Спасибо!
