# Security Policy

## Supported Versions
Currently, only the latest release is supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability, please do not create a public issue.

Instead, contact the author directly through GitHub (create a private Draft Security Advisory in Security -> Advisories).

# Security Policy

## Supported Versions
В настоящее время обновления безопасности поддерживаются только для последней версии.

## Reporting a Vulnerability
Если вы обнаружили уязвимость в безопасности, пожалуйста, **не создавайте публичный Issue**. 
Вместо этого свяжитесь с автором напрямую через GitHub (создайте приватный Draft Security Advisory в разделе Security -> Advisories).
